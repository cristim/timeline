Timeline renderer

FE-2Custom Canvas/WebGL timelineMVP
  • Not DOM, not SVG: thousands of visible objects at 60 fps requires Canvas 2D first, WebGL if profiling demands it.
  • Interaction is Google-Maps-like: scroll/pinch zooms time around the cursor; drag pans; double-click zooms in; the zoom is continuous, while data loading follows discrete buckets T0–T13 (ZOOM-3) with crossfade between bucket datasets.
  • Scale legend adapts: "13.8 Ga … NOW" at T0, "1939 … 1945" at T10, "00:00 … 24:00" at T13.
  • Entities render as: point markers (moments), spans (durations), band lanes grouped by category; labels use collision avoidance with importance priority.
  • Renders from viewport chunk data (API-1) with prefetch of adjacent time-windows and adjacent buckets, so zooming rarely shows an empty lane.
  • Performance budget: first interactive < 3s on mid-range laptop; zoom/pan at 60 fps with 2,000 on-screen objects; memory < 300 MB.

Map

FE-3MapLibre GL JS map, time-synchronizedMVP
  • MapLibre GL JS with our vector tiles (ARCH-3); deck.gl added only if a layer measurably exceeds MapLibre's rendering capacity.
  • Map and timeline are one control: moving the timeline re-requests time-dependent layers (borders, cities, events); panning/zooming the map re-issues the viewport query. Both update the URL (API-6) debounced.
  • Event geometry vocabulary: battle = point/polygon; empire = time-varying polygon; migration = arrow; voyage = route line; war = set of changing fronts (V2).
  • Representation rendering (DM-7): exact = solid lines; estimated = dashed; fuzzy = gradient/heat without hard edge; point_distribution = dots. A legend explains this. Non-negotiable: false precision is a bug.
FE-4Map layersMVP: political + events + cities V2: the rest

Layers are first-class and combinable (e.g. "Languages + political borders, 1910"; "Coal + railways + population, 1850"). MVP ships political borders, events, cities. V2+ adds, in rough order of data availability: religion, trade routes, languages, demographics/population, culture, science/universities, technology spread, economy, environment/climate, infrastructure, military fronts, historical map scans (georeferenced overlays). Each layer = a tile layer + a legend + a data source note; every layer is time-aware.

FE-5Deep-time basemap switchingV2

Beyond ~10k years ago the modern basemap fades to reconstructed paleogeography (ice sheets, coastlines, continental positions; Pangaea at 200 Ma). Basemap selection is automatic from the time cursor with a manual override. Fossils and species render on the reconstructed continents. MVP behavior: modern basemap with a visible "modern coastlines" disclaimer chip when viewing deep time.

Inspector

FE-6Inspector panelMVP

Clicking an entity opens the inspector (no page navigation): name, temporal summary with status badge, key properties (with ranges and value-type flags), classification, description, Wikipedia link, media (Commons images with attribution, ranked YouTube embeds), relationships ("Related: Triceratops, Chicxulub impact"), sources. Actions: focus timeline, focus map, compare, copy link.

Property drill-down: clicking a property shows its claim history ("mass estimates over time: 1980: 5.5t → 2020: 9.x t" with the paper behind each) via /entity/{slug}/claims - the claims model made visible.

  • Map (MVP): default canvas.

  • Graph (V2): relationship/causality explorer (VIS-7).
  • Charts (V2): property time series + records-over-time, events annotated underneath.
  • Scale (V2): to-scale visual comparison (human / T. rex / blue whale / Titanic / Saturn V).

App state and quality bars

FE-9State, accessibility, i18n postureMVP
  • View state (time range, bucket, bbox, layers, selection, view) is a single serializable object, two-way bound to the URL; browser back/forward = view history.
  • Attribution is automatic wherever media/geometry renders (license data from DM-9); a page-level credits popover lists active sources. The basemap carries its own required attribution independent of data layers. The manifest descriptor supplies this complete HTML: <a href="https://github.com/protomaps/basemaps">Protomaps</a> · © <a href="https://www.openstreetmap.org/copyright">OpenStreetMap contributors</a> · <a href="https://docs.overturemaps.org/attribution/">© ESA WorldCover project 2020 / Contains modified Copernicus Sentinel data (2020) processed by ESA WorldCover consortium</a> (<a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>), alongside OpenHistoricalMap and Wikidata credits.
  • Accessibility floor: keyboard navigation for timeline (arrow = pan, +/- = zoom), focus management in inspector, alt text from media metadata, WCAG AA contrast.
  • English-only MVP; all strings externalized from day one.
  • Error surfaces are explicit: a failed viewport load shows a retry chip, never a silently empty timeline.
