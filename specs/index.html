Everything Timeline

A visual, time-aware database of everything: an interactive timeline and map that spans from the Big Bang through human history to scientific projections of the far future, built on open data (Wikidata, OpenHistoricalMap, Wikimedia), a claims-based knowledge graph, and semantic zoom across both time and space.

This spec pack is the implementation contract for the project. Each document carries stable requirement IDs (for example DM-3, API-2) that commits, issues, and PRs should reference. Scope tags mean:

MVP required for the first public release · V2 planned next, design for it now, build later · LATER direction only, do not let it complicate MVP code

The idea in one paragraph

Existing products each get one axis right: Histography does deep time, Chronas / ChronoAtlas / OpenHistoricalMap do historical geography, Histropedia / Wikidata do knowledge breadth, Wikitime comes closest to combining map + timeline but limits itself to ~6,000 years of major human history. Nobody combines TIME × SPACE × KNOWLEDGE in one model. This product makes the basic object "anything with a time and optionally a place" (events, people, species, products, ideas, papers, patents, predictions), stores facts as sourced claims with uncertainty rather than single truths, and renders them through one interface where zooming in time and space simultaneously changes what is shown. The core technical bet is ranking: deciding which ~50 of 5 million things to show at any combination of time scale, geographic scale, and topic filter.

Glossary

TermMeaning
EntityAnything with a time, a place, measurable properties, or relationships: event, person, species, state, invention, paper, product, idea, prediction. See 02.
ClaimA sourced statement about an entity ("T. rex max speed 20–30 km/h per Smith 2024"). Multiple conflicting claims coexist; the system never crowdsources a fake exact number.
Temporal statusOne of observed / documented / estimated / projected / model_dependent / speculative. Controls rendering: the Battle of Waterloo and the heat death of the universe must never look like the same kind of fact.
Semantic zoomChanging the information hierarchy, not just the scale, as the user zooms time and geography together.
Time bucket (T0–T13)Precomputed zoom levels for time, from "whole universe" (T0) down to "hour" (T13). Analogue of map tile zoom levels. See 07.
Importance vectorPrecomputed per-entity scores: global, regional, per-category, per-time-bucket. Drives what renders at each zoom.
Viewport chunksThe core read contract: the client computes static chunk keys from time bucket + window + map tile + category and unions the fetched chunks - no query server. See 05.
Knowledge dateA second, optional time axis: "show this as it was understood in year Y." V2 differentiator. See 01.
Hot / warm / coldStorage tiers: baked serving artifacts (chunks, entity docs, PMTiles) / Parquet model + candidate sets on S3 / original source dumps. See 03.

Global constraints

  • Web-first. Every view has a URL that encodes its state. Desktop/tablet layout first; phone gets a stacked layout. No desktop app in scope.
  • Boring, database-free architecture. A Go baker (embedded DuckDB, tippecanoe) bakes versioned static artifacts to S3; React + MapLibre query them client-side. No database server, no API server, no Kubernetes, no Kafka - see ARCH-8 for the only sanctioned exception.
  • Open data in, provenance kept. Every imported fact records source, source ID, license, and attribution. Media is referenced, never copied.
  • Free browsing forever. Monetization (Pro, education, API) charges for doing work with the data, never for looking at history.
  • Uncertainty is first-class. No fake precision: ranges, competing claims, and confidence render visibly differently from measured facts.
